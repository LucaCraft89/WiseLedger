# WiseLedger

**Team Coin³** · *Agentic Dollars on Bitcoin* hackathon, BLOX Turin, 17–18 October 2026

> A local AI that reads your invoices, catches the fraudulent ones, and pays the good ones with RGB assets on Bitcoin, from your own self-custodial wallet. Nothing leaves your device.

## The idea
Invoice fraud (changed bank details, fake suppliers, duplicate invoices, instructions hidden inside a document) is a real loss for freelancers, small firms and accountants, and paying in digital dollars makes a wrong payment irreversible. WiseLedger puts a private, on-device checkpoint between an invoice and the money:

1. **Upload an invoice** (PDF, image, text, Italian FatturaPA XML).
2. **Analyst** (a local QVAC model) extracts the data and runs safety checks: valid RGB invoice, right asset, amount matches the lines, duplicates, new payee, pressure language, prompt injection. Deterministic rules decide the verdict (ok / review / block); the model only explains it in plain language and never sees the raw invoice text when it writes the explanation.
3. **You confirm** a sentence generated by code from the exact payment ("Pay 25.00 TUSDT to Acme Srl, now").
4. **Treasurer** (a second local QVAC agent) executes the payment with RGB, now or scheduled, through a guard that only lets a confirmed plan move funds. It also labels transfers, creates receive invoices and produces a fiscal report.

## Stack (declared plan, final versions listed at submission)
- **RGB Protocol on Bitcoin v0.11.1** for assets and transfers (rgb-lib through the UTEXO packages `@utexo/wdk-wallet-rgb` and `@utexo/rgb-sdk`), on **Mutinynet** with a local regtest fallback. Test networks only, and an asset we issue ourselves for testing (`TUSDT`, no value).
- **QVAC** (`@qvac/sdk`) for all AI, on device: a Qwen3.5 model with structured output and tool calling, vision/OCR for invoices.
- **WDK** (`@tetherto/wdk` with `@utexo/wdk-wallet-rgb`) for the self-custodial wallet and spend policies.
- TypeScript, Node ≥ 22.17, pnpm workspace, Fastify, React + Vite, `node:sqlite`.
- Possible extra if time allows: RGB over Lightning with `@utexo/wdk-rgb-lightning` (a patched build of a UTEXO fork would be declared here).

### What already works (from the experiments, not product code)
- `@qvac/sdk` loads a Qwen3.5-0.8B model on a laptop and answers a prompt, offline.
- `@utexo/wdk-wallet-rgb` creates a wallet on Mutinynet, issues an experimental test asset `TUSDT` and completes one transfer to `Settled`.
- An experimental RGB-over-Lightning channel and payment with a patched UTEXO node. The compiled node is not in this repository; the two fixes are described in `prior-work/`.

The product is written from scratch during the hackathon, and its test asset is issued again then. All product code in this repository comes from commits dated within the hackathon.
